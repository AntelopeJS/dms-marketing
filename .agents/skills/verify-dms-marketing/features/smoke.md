# Smoke

The fixed journey every verdict runs.

## Sub-features

- `smoke`: an owner adds a website, a visit reaches the collector and the Overview counts its pageview.

## How to get to it (user POV)

- Modules › Marketing › Websites › Add a website.

## Driving it with dms-control

```bash
dms-control journey "$RUN" smoke
```
